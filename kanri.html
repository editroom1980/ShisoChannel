新しいバナーを足す

画像は 1170×107 が規格です。大きさが違う時は、自動で規格に合わせた見本を出すので確認してください。画像は GitHub（アプリの置き場）へ上がり、1〜2分で公開されます。

GitHub の鍵 画像を上げるのに一度だけ必要

鍵の作り方（GitHubの画面で）
  1. GitHub にログインし、右上の自分のアイコン → Settings を開く
  2. 左の一番下 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  3. 名前は「shisochan-kanri」など。Repository access は「Only select repositories」で ShisoChannel だけを選ぶ
  4. Permissions → Repository permissions → Contents を Read and write にする（他はそのまま）
  5. Generate token を押し、表示された github_pat_… を上の欄に貼って「この端末に保存」

※ 鍵はこの端末（ブラウザ）の中だけに保存され、どこにも送りません（画像を上げる時に GitHub へ直接渡すだけ）。

ここには将来、スポンサーの掲載料（請求・入金）と、サポーター会員（月額500円）の登録・継続を並べます。 決済（Stripe など）とサーバー側の処理（Firebase の従量プラン＋Cloud Functions）が必要なため、別の段として設計→承認→実装します。
