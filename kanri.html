鍵の作り方（GitHubの画面で）
  1. GitHub にログインし、右上の自分のアイコン → Settings
  2. 左の一番下 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  3. 名前は「shisochan-kanri」など。Repository access は「Only select repositories」で ShisoChannel だけ
  4. Permissions → Repository permissions → Contents を Read and write に
  5. Generate token を押し、github_pat_… を上の欄に貼って「この端末に保存」

鍵はこの端末のブラウザの中だけに保存されます（画像を上げる時に GitHub へ直接渡すだけ）。
